# Financial Services KPI Analytics Dashboard

## Project Overview

The **Financial Services KPI Analytics Dashboard** is an end-to-end data analytics project designed to monitor and analyze the financial performance of multiple financial institutions.

The project uses synthetic financial data stored in PostgreSQL, SQL-based transformations to calculate business KPIs, and an interactive Streamlit dashboard to visualize performance trends.

The dashboard allows users to analyze financial performance across institutions, locations, product categories, and individual products over time.

## Business Objectives

The project focuses on tracking five key performance indicators (KPIs):

1. **Return on Investment (ROI):** Measures investment profitability.
2. **Assets Under Management (AUM):** Measures the total market value of active investment accounts.
3. **Customer Acquisition Cost (CAC):** Measures the average cost of acquiring a new customer.
4. **Net Promoter Score (NPS):** Measures customer satisfaction and loyalty.
5. **Loan Default Rate:** Measures the percentage of loans classified as defaulted.

The dashboard helps stakeholders monitor trends, compare performance, and identify areas that require attention.

## Key Performance Indicators

### 1. Return on Investment (ROI)

Measures the percentage return generated by investments.

Formula:

`ROI = ((Market Value - Invested Capital) / Invested Capital) * 100`

Calculated using monthly investment account snapshots.

### 2. Assets Under Management (AUM)

Measures the total market value of eligible active investment accounts.

Formula:

`AUM = SUM(Market Value)`

Accounts are considered based on their opening and closing dates.

### 3. Customer Acquisition Cost (CAC)

Measures the average cost incurred to acquire a new customer.

Formula:

`CAC = Total Marketing and Sales Expenses / New Customers Acquired`

### 4. Net Promoter Score (NPS)

Measures customer loyalty using survey ratings from 0 to 10.

- Promoters: Ratings 9–10
- Passives: Ratings 7–8
- Detractors: Ratings 0–6

Formula:

`NPS = % Promoters - % Detractors`

The result ranges from -100 to +100.

### 5. Loan Default Rate

Measures the percentage of loans classified as defaulted.

Formula:

`Loan Default Rate = (Defaulted Loans / Total Loans) * 100`

Loan status is evaluated using the latest available status as of each reporting month.

## SQL Data Modeling and Aggregation

SQL was used to transform source data into monthly KPI aggregate tables.

The following aggregate tables were created:

- `monthly_roi`
- `monthly_aum`
- `monthly_cac`
- `monthly_nps`
- `monthly_loan_default_rate`

Each aggregate table contains 60 monthly records covering January 2022 to December 2026.

Two dashboard views were also created:

- `monthly_kpi_dashboard` – Consolidated monthly KPI data across all institutions.
- `monthly_institution_kpi_dashboard` – Monthly KPI data at the institution level.

The institution-level dashboard view contains 240 records (60 months × 4 institutions).

SQL concepts used include:

- Common Table Expressions (CTEs)
- Joins and aggregations
- Conditional aggregation
- `FILTER` clauses
- Window and date-based analysis
- `DATE_TRUNC`
- `GENERATE_SERIES`
- `LATERAL` joins
- Historical status analysis

## Interactive Dashboard

The Streamlit dashboard provides an interactive interface for exploring financial performance.

### Dashboard Features

- Five KPI summary cards.
- Institution-level filtering.
- Location-based filtering.
- Product category filtering.
- Individual product filtering.
- Custom date range selection.
- Monthly KPI trend charts.
- Interactive Plotly visualizations.
- Detailed monthly KPI data.
- CSV export of filtered results.
- PostgreSQL integration for retrieving analytical data.

### Dynamic Filtering

Users can analyze performance using combinations of:

- All Institutions or an individual institution.
- All Locations or a specific location.
- Investment or Loan product categories.
- Individual financial products.
- Custom reporting periods.

The dashboard adjusts the relevant KPIs based on the selected product category. For example, ROI and AUM are not applicable when analyzing loan products, while loan default rate is not applicable when analyzing investment products.

## Installation and Setup

### Prerequisites

- Python 3.10 or later
- PostgreSQL
- Git

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd financial-services-analytics
```

### 2. Create a Virtual Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure PostgreSQL

Create a PostgreSQL database and configure the connection details in:

`.streamlit/secrets.toml`

```toml
[postgresql]
host = "localhost"
port = 5432
database = "financial_services_analytics"
username = "YOUR_DATABASE_USER"
password = "YOUR_DATABASE_PASSWORD"
```

**Important:** Never commit `secrets.toml` or database credentials to GitHub.

### 5. Generate Synthetic Data

```bash
python data_generation/generate_all.py
```

This generates the synthetic financial dataset.

### 6. Create KPI Aggregate Tables

Run the SQL aggregation script:

```bash
psql -h localhost -U YOUR_DATABASE_USER \
-d financial_services_analytics \
-f sql/aggregate_tables.sql
```

Ensure that the required source tables have been created and populated before running this script.

Create the dashboard views using the corresponding SQL definitions in your project.

### 7. Launch the Dashboard

Run the application from the project root:

```bash
python -m streamlit run dashboard/app.py
```

Open the local URL displayed in the terminal, usually:

`http://localhost:8501`
